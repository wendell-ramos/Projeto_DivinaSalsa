# Segurança

## Versão mantida

Somente a versão publicada a partir da branch `main` recebe correções de segurança.

## Como comunicar uma falha

Não publique credenciais, dados pessoais ou detalhes exploráveis em uma issue pública.
Comunique a falha de forma privada ao proprietário do repositório, informando:

- página ou recurso afetado;
- passos mínimos para reproduzir;
- impacto observado;
- evidências sem dados sensíveis reais.

Não teste exclusão, alteração em massa, indisponibilidade ou acesso a dados de terceiros.

## Escopo atual

O site público é uma exportação estática: não possui login, formulário, API ou banco de dados.
O futuro painel administrativo terá uma revisão de segurança própria antes de ser publicado.
