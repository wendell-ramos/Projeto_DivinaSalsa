# Divina Salsa Restaurante

Protótipo inicial do novo site institucional do Divina Salsa Restaurante, localizado no Passeio Pedra Branca, em Palhoça/SC.

## Tecnologias

- Next.js com App Router
- React e TypeScript
- Tailwind CSS
- Lucide Icons

## Desenvolvimento

```bash
npm install
npm run dev
```

Antes da publicação, confirme com o restaurante horários, contatos, preços, textos, fotografias e funcionalidades definitivas.
